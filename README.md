# China 2026 — the people's version

Tarek's must-do list for Beijing, Xi'an, Chengdu and Chongqing, 20 Sep – 3 Oct 2026.

- `data.py` — all content: cities, days, and every stop (title, one-liner, tip, full story). Edit this to change the list.
- `places.json` — coordinates and Wikimedia Commons photo for each stop, keyed by the stop id.
- `build.py` — turns the two files above into `index.html`.
- `.github/workflows/pages.yml` — rebuilds and publishes to GitHub Pages on every push to `main`.

Build locally: `python3 build.py` (Python 3, no dependencies).
